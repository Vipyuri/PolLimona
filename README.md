# Пол-лимона — сайт-визитка кофейни 🍋

Домашняя страница семейной **dog friendly** кофейни-кондитерской «Пол-лимона»
у парка Екатерингоф в Санкт-Петербурге.

Сайт полностью статический: чистые HTML + CSS + JavaScript, без сборки и
зависимостей. Открывается где угодно — от локального файла до любого хостинга.

## 📁 Структура проекта

```
PolLimona/
├── index.html          — вся страница (тексты, секции, меню)
├── css/
│   └── style.css       — стили (цвета, шрифты, адаптив, анимации)
├── js/
│   └── main.js         — меню-бургер, табы меню, лайтбокс, анимации
└── img/
    ├── favicon.svg     — иконка вкладки (ломтик лимона)
    ├── logo-original.png — оригинальный логотип с Яндекс Карт (для истории)
    └── photos/         — фотографии кофейни (взяты с Яндекс Карт)
        ├── interior-window.jpg — зал: гирлянды и ёлка
        ├── latte.jpg            — капучино и домашний торт
        ├── pastry-case.jpg      — витрина с десертами
        ├── loaf-cakes.jpg       — кексы и кейк-попсы
        ├── interior-corner.jpg  — свет и живые растения
        └── atmosphere.jpg       — фон секции-приглашения
```

## 👀 Как посмотреть сайт

**Вариант 1 — онлайн (GitHub Pages, бесплатно).** Сайт уже опубликован:

### 🔗 https://vipyuri.github.io/PolLimona/

Эту ссылку можно отправить заказчику или кому угодно — сайт работает
без домена и хостинга. При обновлении файлов в репозитории сайт
пересобирается автоматически (обычно ~1 минута).

**Вариант 2 — локально.** Просто откройте `index.html` двойным кликом
(лучше — через локальный сервер, чтобы работала карта):

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## ✏️ Как вносить правки

| Что меняем | Где |
|---|---|
| Тексты (о нас, слоганы, отзывы) | `index.html` — ищите нужную секцию по комментариям `<!-- ==== -->` |
| Цены и позиции меню | `index.html`, секция «МЕНЮ», списки `#panel-drinks` и `#panel-desserts` |
| Часы работы | `index.html`: секция «Контакты», подвал и блок `JSON-LD` в `<head>` |
| Телефон | поиск по `+7 (993) 216-57-05` / `+79932165705` |
| Цвета | `css/style.css`, блок `:root` (переменные `--gold`, `--lemon` и т.д.) |
| Фотографии | замените файлы в `img/photos/`, сохранив имена — или добавьте свои и поправьте пути в `index.html` |

⚠️ **Цены в меню — примерные** (частично взяты с Яндекс Карт). Перед публикацией
сверьте их с актуальной витриной. Часы работы тоже стоит перепроверить:
на Яндекс Картах указано Пн–Пт 09:00–21:00, Сб–Вс 10:00–21:00.

## 🎨 Дизайн-заметки

- Фирменная палитра построена на реальном логотипе кофейни: латунь `#B9934E`
  на кремовом фоне + лимонный акцент `#F2C230`.
- Шрифты: **Playfair Display** (заголовки, как в логотипе), **Golos Text**
  (текст), **Caveat** (рукописные акценты) — все с поддержкой кириллицы.
- Фото и данные — с [карточки кофейни на Яндекс Картах](https://yandex.ru/maps/org/pol_limona/27024449023/)
  (рейтинг 4.9, отзывы, цены на капучино).
- Карта — встроенный виджет Яндекс Карт (бесплатный, без API-ключа).

## 🚀 Публикация на своём хостинге (когда купите)

Просто загрузите все файлы из репозитория в корень хостинга —
ничего собирать не нужно. Подойдёт любой shared-хостинг, VPS с nginx,
Netlify, Vercel или GitHub Pages.

💡 **Когда купите домен**, его можно подключить прямо к GitHub Pages
(Repo → Settings → Pages → Custom domain) — тогда и хостинг не нужен:
файлы сайта и публикация остаются в этом же репозитории, просто
обновите ссылки `og:url` / `og:image` в `index.html` на новый адрес.
